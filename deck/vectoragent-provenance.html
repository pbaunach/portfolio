03Why Now

Autonomy is the whole problem

1Today

A person picks the icon library once, at the start, and reads the pull request before it merges.

2Soon

The agent picks, mid-build, hundreds of times across a session, and nobody reads each choice.

3Then

The only record that can exist is one the machine wrote itself, at the instant it chose.

Provenance cannot be a review step.

It has to be made at the moment of the choice.

04Solution

Make the payment the license

One event, two records

The agent pays, and that settlement is the license. There is no separate entitlements database to query, trust, or keep alive.

Checkable without us

It is a public ledger entry. A compliance tool resolves it directly, and it still verifies if VectorAgent no longer exists.

Written by the thing that chose

The record is created in the same call that made the decision. Nothing is reconstructed afterwards from logs or memory.

05Architecture

Three standards we did not have to invent

Tools · MCP

How the agent finds us

Model Context Protocol is how LLMs reach outside tools now. Agents already know how to call a tool server, and they look for them in directories. Nobody has to teach them.

> tools/call fetch_vector_icon

Payments · x402

How it pays without asking

HTTP 402 finally has a spec behind it. An agent settles a sub-cent payment in the request header and moves on.

Backed by
VisaMastercardStripeGoogleAWS

< HTTP/1.1 402 Payment Required

Record · Stellar

Why the proof outlives us

A signature we issue proves only that we issued it, and it dies with the company. A public entry is checkable by anyone. Sub-cent fees are what make a record per asset cost less than the asset.

> SEP-41 USDC · Soroban · ~3s

All three already exist.

The registry that sits on top of them does not.

07Business Model

No buyer, no seat. The agent spends its own wallet.

Tier 1$0.000

A free baseline

Solves the cold start: an agent that calls the tool always gets something back. How big the set is, and what goes in it, is still open.

Tier 2$0.002

When the free set won't do

Niche, brand-specific, or indemnified work, bought one asset at a time, at the moment it is needed.

The agent's math

Cheaper than doing it itself

Self-generating costs ~300 output tokens, a broken-path risk, and a rework cycle. Fetching costs a fraction of a cent and arrives licensed.

90%
10%
90% to the creator, settled per use. Iconfinder pays 70%. 10% stays with VectorAgent

Not settledThe operator funds a capped wallet once and nobody approves a purchase after that. The price still has to sit under what self-generating costs the agent and above what the platform needs, and at $0.002 those do not both hold yet.
